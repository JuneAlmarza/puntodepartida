# puntodepartida
Una plataforma interactiva para que jóvenes diseñadores descubran su propio mapa creativo.

. de partida es una experiencia web diseñada para acompañar a estudiantes y jóvenes profesionales del diseño en un proceso de autoexploración. A través de un recorrido narrativo y un cuestionario interactivo, la plataforma ayuda a identificar un Top 3 de áreas de diseño que resuenan con la identidad, intereses y sensibilidad de cada usuario.

El proyecto combina narrativa editorial, interactividad web y visualización de referencias para crear un espacio íntimo, claro y orientado a la toma de decisiones.

El propósito de . de partida es ofrecer un punto de claridad en un momento de confusión habitual:
“¿Qué camino dentro del diseño encaja realmente conmigo?”

La plataforma no pretende dar respuestas absolutas, sino abrir un espacio de reflexión guiada donde cada usuario pueda:
Ubicarse en su contexto actual
Conocerse a través de preguntas clave
Sumergirse en referencias visuales
Organizar sus intereses en un mapa personal
